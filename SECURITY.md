# Security

Report suspected vulnerabilities through the [ASO Skill contact page](https://www.asoskill.com/contact) or by emailing `viktor@asosuite.com`. Please do not disclose security issues or secrets in a public GitHub issue.

This repository contains public instructions and declarative connection metadata. It contains no server implementation, user data, credentials, OAuth client secrets, or API keys. Authentication happens directly between a compatible MCP client and `https://api.asoskill.com` through OAuth authorization code with S256 PKCE.
